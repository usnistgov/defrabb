## Root Cause Analysis

### Finding 1: 619 SNP FN = FP (Phasing Mismatch)

**Category:** **A - Pipeline Artifact** 🚫  
**Root Cause:** `truvari anno trf` strips phasing during TRF annotation  
**Impact:** 619 identical variants differ only in phasing representation  
**Decision:** **REJECT artifact - Fix required in v0.023**

#### Evidence

Processing chain shows phasing lost at trfanno step:
```
1. Raw dipcall:        chr1  89177  GT:AD  1|1:0,2  ✓ PHASED
2. Rename:             chr1  89177  GT:AD  1|1:0,2  ✓ PHASED
3. norm:               chr1  89177  GT:AD  1|1:0,2  ✓ PHASED
4. fix_XY_genotype:    chr1  89177  GT:AD  1|1:0,2  ✓ PHASED
5. trfanno:            chr1  89177  GT:AD  1/1:0,2  ✗ PHASING LOST ← CULPRIT
6. Final benchmark:    chr1  89177  GT:AD  1/1:0,2  ✗ UNPHASED

v5.0q comparison:      chr1  89177  GT:AD  1|1:0,2  ✓ PHASED
```

Hap.py interprets `1/1` vs `1|1` as genotype mismatch.

#### Solution for v0.023

Change `bench_vcf_processing` profile from `xy_trf` to `xy_fix` for smvar:
- `xy_trf`: `fix_XY_genotype` + `trfanno` (loses phasing)
- `xy_fix`: `fix_XY_genotype` only (preserves phasing)

**Rationale:** TRF annotations are primarily for structural variants; unnecessary for smvar benchmarking.

**Expected result:** SNP F1 0.9998 → 1.0000

**Documentation:** `docs/issues/happy-phasing-mismatch-v5q.md`

### Finding 3: -408 KB GRCh37 (chr2:114026547-114444739)

**Category:** **C - Exclusion Change** ✓  
**Root Cause:** Segmental duplication excluded in v0.022, included in v5.0q  
**Impact:** 7 intervals, 408 KB (0.015% of baseline)  
**Decision:** **ACCEPT** (more conservative exclusion criteria)

#### Evidence

Region matches segdup exclusion in v0.022:
```bash
$ grep "^2.*11402" resources/exclusions/GRCh37/segdups_slopmerge_sorted.bed
2  114026547  114444739
```

v0.022 uses updated exclusion criteria that exclude this segdup region, while v5.0q (based on older exclusion set) includes it. **This represents increased stringency, not a regression.**

### Finding 4: +249 KB CHM13 Regions

**Category:** **F - Intended Improvement** ✓  
**Root Cause:** Assembly-supported regions in T2T CHM13 reference  
**Impact:** 2,047 intervals (+0.009% total coverage)  
**Decision:** **ACCEPT**

Smallest expansion across all references, consistent with high-quality T2T assembly.

## Overall Assessment

### Strengths
- ✅ **Nearly perfect region concordance** (≥99.98%)
- ✅ **Perfect INDEL metrics** (F1 = 1.0000)
- ✅ **GRCh38/CHM13 perfect supersets** of v5.0q
- ✅ **Root cause identified** for all differences
- ✅ **Solutions designed** for artifacts

### Known Issues
- ⚠️ **Phasing artifact** from `truvari anno trf` (619 SNP FN/FP)
  - **Impact:** SNP F1 = 0.9998 instead of 1.0000
  - **Fix:** Use `xy_fix` profile in v0.023
  - **Workaround:** None needed for v0.022 release (document known issue)

### Recommendations

1. **Release v0.022** with documented phasing issue in CHANGELOG
2. **Fix phasing** in v0.023 by using `xy_fix` instead of `xy_trf` for smvar
3. **Spot-check expansion regions** when time permits (not blocking)
4. **Apply validation framework** to all future benchmarks before release
