## Architecture Summary

### Component 1: Parameter Profile Registry
**Pattern:** `vc_param_id` in analyses table → profile name → `config/_xxx_params[profile]`

**Profiles:**
- Dipcall: 4 variants (z1k, z2k, z5k, z10k)
- PAV: 3 variants (giab, strict, lenient)
- Exclusions: 3 variants (conservative, standard, aggressive)

**All schema-validated, backward compatible.**

### Component 2: Sweep Generator
**Input:** YAML with fixed + sweep dimensions  
**Output:** Analyses table TSV with cross-products

**Intelligence:**
- vc_id reuse: Share variant calls (3-6 hours each) across downstream sweeps
- Cost estimation: Runtime + storage projections
- Validation: Duplicate detection, schema checks
- Safety: Dry-run mode, max-analyses limit

### Component 3: Baseline Comparison & Scoring
**Input:** Results directory + baseline analysis_id  
**Output:** Ranked parameter sets with deltas

**Features:**
- Top-N selection by metric (F1/precision/recall)
- Regression detection with threshold
- Markdown summary with recommendations

### Component 4: Output Reuse (Snakemake-Native)
**Mechanism:** Same vc_id → same outputs → automatic reuse

**Sweep generator assigns shared vc_ids** to analyses differing only in:
- exclusion_set
- vcf_processing  
- eval_cmd, eval_comp_id, eval_params

**No pipeline changes needed** - Snakemake handles reuse via vc_id matching.

## Multi-Genome Workflow Example

### Stage 1: HG002 Optimization (18 analyses)
```yaml
fixed: {ref: GRCh38, asm: HG002, eval_comp: v5.0q-smvar}
sweep:
  vc_param_id: [z2k, z5k, z10k]
  exclusion_set: [conservative, standard, aggressive]
  vcf_processing: [trf, xy_trf]
```
- 18 analyses, 3 unique variant calls (6x reuse)
- ~24 hour runtime estimate

### Stage 2: Scoring
```bash
scripts/score_param_sweep.py --results-dir hg002_opt --top-n 3
```
- Ranks by F1 vs v5q baseline
- Identifies top-3 param sets

### Stage 3: 4-Genome Validation (36 analyses)
```yaml
fixed: {ref: GRCh38, vcf_processing: xy_trf}
sweep:
  asm_id: [HG008N, HG008T, NA12878, HG005]
  vc_param_id: [z5k, z2k, z10k]  # winners from HG002
  exclusion_set: [aggressive, standard, conservative]
```
- 36 analyses, 12 unique variant calls (3x reuse)
- ~78 hour runtime estimate

### Stage 4: Cross-Genome Analysis
```bash
scripts/compare_evaluations.py --results-dir 4genome_val --regions
```
- Identify consistent winners
- Genome-specific outliers
- Discrepancy hotspots for refinement
