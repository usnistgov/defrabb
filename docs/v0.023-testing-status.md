## Summary

Fixed critical bugs in v0.023 parameter optimization framework and verified core functionality. The sweep generator now produces schema-compliant analyses tables that pass Snakemake validation.

## Fixes Applied

### 1. `bench_id` uniqueness bug
**Issue:** Sweep generator only included `exclusion_set` in bench_id, not `vcf_processing`. This caused duplicate (eval_id, bench_id) pairs when sweeping vcf_processing parameters.

**Fix:** Updated bench_id generation to include both exclusion_set and vcf_processing suffixes.

**Location:** `scripts/generate_param_sweep.py:168-179`

**Verified:** ✅ hg002_smvar_opt.yml dry-run now validates cleanly (18 unique analyses)

### 2. Schema compliance
**Issue:** Generated tables used user-friendly column names (`ref_id`, `vcf_processing`) instead of schema names (`ref`, `bench_vcf_processing`), and was missing required columns.

**Fix:** 
- Added column mapping: `ref_id` → `ref`, `vcf_processing` → `bench_vcf_processing`
- Added schema-required columns with defaults: `eval_comp_id_is_truth`, `eval_truth_regions`, `eval_target_regions`, `bench_bed_processing`
- Reordered columns to match analyses-schema.yml
- Used `na_rep=""` in to_csv to avoid pandas NaN issues

**Location:** `scripts/generate_param_sweep.py:131-190`

**Verified:** ✅ Generated tables pass Snakemake schema validation

### 3. Missing executable bit
**Issue:** `scripts/compare_evaluations.py` wasn't executable, causing `score_param_sweep.py` to fail with permission error.

**Fix:** `chmod +x scripts/compare_evaluations.py`

**Verified:** ✅ score_param_sweep.py runs successfully on v0.022 fulltest data
